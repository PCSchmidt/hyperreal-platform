# The Hyperreal Collection - Product Overview

**Status:** Draft v1 - concept stage; working names only (titles are common phrases and need a trademark/name check before any public launch).

## Premise
A set of competitive simulation games in which realism is part of the skill, built on one deterministic, replay-verified, agent-ready platform. Each title is a different physical domain; all share the same competitive spine: seeded scenarios, input-log replays, server-side re-simulation, calibrated ratings, and bot opponents.

## Titles
| Title | Domain | Core skill | Distinct showcase |
|---|---|---|---|
| Dark Fleet (first) | Maritime hidden-information contest | Evidence fusion, deception, tasking | Agents + benchmark; tracker; self-play |
| Horizon Line | Precision-rifle sport | Environmental perception | Learned wind reader; optics rendering |
| Gale Force | Sailing racing | Tactics under shifting wind | Rules engine; multi-agent RL; ocean |
| Depth Charge | Breath-hold diving | Efficiency under physiological stress | Safe RL; underwater optics |

## Shared player-facing features (target)
- One launcher listing installed titles with shared display name and per-title/role ratings.
- Daily seeds and verified leaderboards per title.
- A replay library with scrubbing, comparison and export.
- Optional agent features, always off by default in ranked play and never required.
- Consistent accessibility options, settings, saves and crash-safe data handling.

## Brand and naming (open)
Collection name, per-title names and iconography are undecided. Action: search for conflicts and trademarks for each name before publishing builds; consider descriptive subtitles.

## Distribution (open)
Source and specifications are public. Builds, if released, would be free downloads (for example on a hobbyist storefront) with licenses for assets recorded; no monetization is planned.

## What each title proves (portfolio view)
- Deterministic simulation engineering and verification (all).
- ML engineering with baselines, ablations, reproducibility and model cards (all).
- Agent engineering: tool use, orchestration, grounding, observability, evaluation and injection security (Dark Fleet primary).
- Real-time graphics and technical art in Unreal (later gates).
- Data engineering with license-tracked, hash-pinned datasets (all).
